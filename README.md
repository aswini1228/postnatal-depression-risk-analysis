# postnatal-depression-risk-analysis
🧠 Postnatal Depression Risk Prediction System  Machine Learning–based healthcare project that predicts the risk of postnatal depression in mothers using emotional and behavioral symptoms.  The system analyzes factors like sadness, anxiety, sleep problems, guilt, bonding issues, and irritability to identify high-risk cases.  
Features
📊 Data Collection and Preprocessing
🧹 Data Cleaning and Missing Value Handling
🤖 Machine Learning-Based Risk Prediction
🧠 Postpartum Depression Risk Analysis
📈 Exploratory Data Analysis (EDA)
🔍 Symptom-Based Mental Health Assessment
⚡ Real-Time Prediction System
🌐 Interactive Streamlit Web Application
📝 User-Friendly Input Interface
📋 Instant Risk Assessment Results
📉 Model Performance Evaluation
🎯 Early Identification of Mental Health Risks
